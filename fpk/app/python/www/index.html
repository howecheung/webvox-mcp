联网查询MCP

StackChan / 小智语音机器人的实时联网搜索 MCP 服务

配置说明
  1. MCP 服务地址：从 xiaozhi.me 控制台复制的 wss://…?token=… 整串地址。
  2. 服务商二选一：默认推荐阿里百炼 WebSearch MCP（需先在百炼 MCP 广场开通，前 2000 次免费）；用智谱则选智谱 GLM 并填对应 Key。
  3. 点“保存并重连”，再到“运行日志”查看连接情况。
密钥/令牌不会明文回显或写日志；留空保存表示不改，勾选“清除”可删除已保存密钥。

1 · 小智连接

0 - 1000，0 表示一直重试。到达上限就停止自动重连并在下方标红，可点“重新连接”恢复；容器不会被反复重启。

2 · 搜索服务商

3 · 语音设备优化（联网查询工具）

简要模式只取摘要，不请求网页全文；详细模式才会取完整正文。
字符数，500 - 50000。超出按条目截断，避免语音端上下文爆炸。
3 - 60 秒。语音端等不了太久，超时直接返回错误让机器人先说话。
0 - 3600 秒，0 表示关闭。同一搜索词在缓存期内直接复用结果，不重复计费。
开启后用系统 DPAPI 加密落盘，配置拷到别的机器也解不开；NAS 容器无 DPAPI，会自动退回 600 权限明文。

4 · 网页抓取（fetch_url 工具）

DeepSeek 官方 Fetch 接口按成功请求计费（5 元 / 1000 次）；本地抓取不产生外部费用。
字符数，500 - 20000。

5 · 测试与用量

用当前已保存的配置直接搜一次，验证 Key 和网络是否正常（会正常计费）。
